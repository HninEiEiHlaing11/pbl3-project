NoiseMap NYC

Predicting Urban Neighbourhood Noise for Apartment Renters
Problem Statement

Urban renters often judge neighbourhood noise based on how it sounds today, yet the most disruptive noise—especially construction—is a future event that current noise maps cannot reveal. A block that seems quiet during a February viewing may face a major construction project by May, exposing tenants to chronic noise that harms health and reduces quality of life. Research also shows that noise levels above 55 dB can reduce rental values by roughly 2% per decibel, making noise both a health and financial concern. Existing tools only display static, present‑day noise and cannot forecast how noise will change or which sources will drive it. This project addresses that gap by predicting future noise conditions at a fine‑grained 50×50 metre resolution.

Objectives
  • 1Predict neighbourhood noise levels up to 12 months ahead for every 50×50 metre grid block across New York City
  • 2Decompose each prediction into plain‑language noise source contributions using SHAP (construction, traffic, baseline activity)
  • 3Present noise level predictions and dominant noise sources as human‑readable labels accessible to non‑technical users
  • 4Provide renter‑specific tools to assess noise risk within their specific tenancy period, including financial impact estimates
  • 5Deliver all outputs through an interactive web map
Related Works
HowLoud
Provides a location-based Soundscore derived from modelled environmental noise sources.
NYC Noise Complaint Map
Visualises compiled 311 noise complaint data across NYC neighbourhoods as a historical reference.
SONYC (NYU)
Uses a network of acoustic sensors and machine learning to monitor and classify urban noise sources in real time across New York City.
These existing works focus on current or historical noise conditions. None provide forward‑looking predictions, source‑level attribution via explainable AI, or renter‑specific decision tools—the gaps this project addresses.
Proposed Approach
Data Processing
1
Data Ingestion
Raw data from multiple open sources is ingested and read into a consistent format using Pandas. Inputs include construction permits, traffic counts, zoning data, noise complaints, subway activity, nightlife locations, and SONYC sensor readings.
2
Preprocessing
Raw data is cleaned and standardised into a consistent format compatible with the spatial processing and modelling pipeline.
3
Spatial-Temporal Snapping
GeoPandas is applied to snap all data sources to a standardised 50×50 metre grid aggregated by month, mapping every complaint, permit, and sensor reading to a unified grid matrix.
4
XGBoost Model Training
An XGBoost regression model is trained on the historical matrix to learn the relationship between urban activity inputs and actual decibel levels. The model then generates 12‑month predictions using future permits, seasonal traffic projections, subway schedules, and nightlife patterns.
5
SHAP Attribution
SHAP is applied to break each prediction into clear, plain‑language noise source contributions: construction, traffic, and everyday neighbourhood activity.
6
Confidence Scoring
Each grid block receives a High, Medium, or Low confidence rating based on sensor coverage, permit completeness, and historical consistency.
Data Visualisation

The output is displayed through an interactive map built in Streamlit and PyDeck. Grid blocks are colour‑coded by predicted noise level, and users can click any grid to view SHAP source breakdown, confidence rating, a noise timeline, lease overlap calculator with financial impact estimate, and neighbourhood comparison tools. Users may also input their floor level to receive an adjusted noise estimate.

Features
Prediction Map
Colour‑coded 50×50m grids with current and monthly time toggle
Noise Source Badges
Plain‑language SHAP labels showing contributions from construction, traffic, and baseline activity
Noise Timeline
Line chart showing predicted noise trajectory across the 12‑month forecast window
Lease Overlap Calculator
Highlights predicted noisy months and estimates financial impact (2% rent reduction per dB above 55)
Neighbourhood Comparison
Side‑by‑side noise profiling of two addresses across all prediction features
Confidence Indicator
High, Medium, Low reliability rating based on sensor and permit data availability
Floor‑Level Adjustment
Higher floors may experience reduced street‑level noise; users can input floor level for adjusted estimates
