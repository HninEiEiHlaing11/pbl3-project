NoiseMap NYC — System Requirements
1. Introduction

This Requirements Specification Document defines the functional and non‑functional requirements for the NoiseMap NYC system.

2. System Overview

NoiseMap NYC is a predictive urban noise forecasting platform that provides 12‑month noise predictions at a 50×50 metre resolution across New York City.

3. Functional Requirements
ID Description Priority
FR‑01 The system shall ingest and preprocess data from construction permits, traffic counts, subway schedules, nightlife locations, zoning data, 311 complaints, and SONYC sensors. High
FR‑02 The system shall aggregate all data into a unified 50×50 metre monthly grid. High
FR‑03 The system shall train an XGBoost model to predict future noise levels. High
4. Non‑Functional Requirements
  • 1Performance: Map interactions should respond within 300 ms.
  • 2Usability: Interface must be understandable to non‑technical renters.
  • 3Reliability: Predictions must include confidence scoring.
5. Constraints

The system depends on the availability and completeness of NYC Open Data sources.

6. Assumptions

It is assumed that future construction permits and traffic patterns follow historical seasonal trends.
